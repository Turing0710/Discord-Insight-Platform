# DiscordChatExporter.Cli

Place the DiscordChatExporter CLI runtime files in this directory for local development.

Expected examples:

- Windows: `DiscordChatExporter.Cli.exe` plus its required `.dll` files
- Linux/macOS: `DiscordChatExporter.Cli` or `DiscordChatExporter.Cli.dll`

Download releases from:

https://github.com/Tyrrrz/DiscordChatExporter/releases

Notes:

- The CLI binaries are intentionally not committed to this repository.
- The production Dockerfile downloads the Linux x64 CLI automatically during image build.
- DiscordChatExporter is a third-party project with its own license and terms.
